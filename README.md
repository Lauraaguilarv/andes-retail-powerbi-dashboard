# andes-retail-powerbi-dashboard
Dashboard comercial desarrollado en Power BI para analizar ingresos, costos, utilidad y desempeño de ventas de Andes Retail Group durante 2024-2025.
El proyecto busca transformar datos comerciales en información útil para identificar tendencias, evaluar la rentabilidad y apoyar la toma de decisiones.

🎯 Objetivos
Analizar los ingresos totales y su evolución anual.
Comparar ingresos entre países.
Analizar el desempeño por segmento de cliente.
Identificar las categorías de producto con mayores ingresos.
Evaluar costos, utilidad y margen de utilidad.
Facilitar la interpretación de los resultados mediante visualizaciones interactivas.

📈 Dashboard
El dashboard incluye:
Ingresos totales.
Costo total.
Utilidad.
Margen de utilidad.
Ingresos por año.
Ingresos por país.
Ingresos por segmento de cliente.
Ingresos por categoría de producto.
Filtros por país, año y nivel de venta.

🛠️ Herramientas utilizadas
Power BI
Power Query
DAX
Excel / archivos de datos

💡 Principales aprendizajes
Este proyecto permitió desarrollar habilidades en limpieza y transformación de datos, creación de indicadores, construcción de dashboards interactivos y análisis de resultados comerciales.
